# Novel reader font and parser research

* **Noto Naskh Arabic** (`novel_noto_naskh_arabic.ttf`, variable weight, unmodified): Copyright 2022 The Noto Project Authors. SIL Open Font License 1.1, permitting embedding/redistribution. Source: https://github.com/google/fonts/tree/main/ofl/notonaskharabic . Full license distributed in `app/src/main/assets/novels/licenses/NotoNaskhArabic-OFL.txt`; license reference https://openfontlicense.org/ . No website attribution or hotlink is required for this local font.
* LNReader https://github.com/lnreader/lnreader and plugins https://github.com/lnreader/lnreader-plugins were researched. Plugin license: MIT (2021 Rajarshee Chatterjee). KolNovel LightNovelWP configuration and Sunovels/SeaNovel adapters were compared with live pages.
* IReader https://github.com/IReaderorg/IReader and extensions https://github.com/IReaderorg/IReader-extensions were researched. Extension repository license: MPL-2.0. KolNovel/Sunovels/SeaNovel adapters were studied for public navigation/order edge cases.

The Mangaro adapters are independently written from inspected live responses. No reference adapter source files were copied into this project. There was no Cenele adapter in the inspected trees; Cenele was implemented from its actual public page and read-only UI chapter-list requests.

Novel text and covers belong to their respective rights holders. No chapter text/HTML or downloaded third-party cover asset is committed or packaged. Runtime public-page rendering in this private development prototype is not a public-distribution license. Owner authorization is required before public rollout.
