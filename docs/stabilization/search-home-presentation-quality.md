# Search and Home presentation quality

Base: private integration `5b998029d519481070677d539ae65007b3a1f625`.

Search and Home now explicitly opt in to reversible presentation grouping through the existing identity resolver. Strict canonical identity remains the default for identity consumers. Exact informative names with missing credits can share a presentation group; mutual declared names can support translations. Trusted contradictory IDs, creator evidence, media and sequel evidence still veto a group. Complete-link checks prevent an unknown contributor from bridging conflicting works. `presentation:` keys never approve a canonical library identity. Every source-qualified edition remains in the selector.

The shared edition comparator ranks availability and non-conflicting observed unique chapter counts before a positive reader sample. An unknown sample is different from a failed reader. Complete indexes, positive samples and source reliability resolve comparable evidence. Publication dates remain publication dates; fetch completion order cannot win a tie. Explicit selections and library records remain unchanged.

Card eligibility is independent from identity. Safe source work routes require positive work metadata, an actual index or parser-supplied cover evidence. Pending candidates remain available for bounded enrichment and diagnostics, but not normal work cards. Confirmed listing routes and security challenge responses are rejected. Known work metadata survives temporary failures. A zero chapter count does not reject a valid newly published work.

Home no longer recursively refreshes all sources when request-health events recover. Metadata changes are coalesced; unchanged projections use a per-group evidence cache. Known editions are indexed once per evidence revision rather than scanned and resolved repeatedly for every shelf. The edition chooser consumes the already-rendered source-qualified group. Pending Popular validation is limited to four metadata requests per fetch, shared concurrency three, two seconds per request; it fetches no chapter lists or chapter bodies.

Changed legacy Kotlin files are formatted in full under the original rules, and their content exemptions are permanently retired. No advertising, production backend, account system, XP, version, signature, or stored reading identity is changed.

Historical tests that required duplicate presentation for missing credits now assert the requested reversible grouping while checking that canonical roots and source editions remain separate. Positive transport fixtures supply explicit work-card evidence. Conflict and source-data-preservation tests are retained. Signed Release runtime results, provider limitations and frame measurements are reported separately from JVM fixtures; synthetic 15-versus-200 coverage is not a claim of a live provider reproduction.
